## 피그마 대비 차이 (완료 화면)
## 홈
- 비용 USD(₩ 아님, D17), 비용 카드에 예산 게이지 추가
- "최근 실행 5건" 섹션 추가(prompts 요구), 승인 카드에 바로 승인/거부
- 아이콘 자리에 이모지
## 스튜디오
- 검색·목록/카드 둘 다·카드 메뉴(…)·새로 만들기 드롭다운 추가
- 에이전트 6, 워크플로 8 (Figma 4/5)
- 상태 배지 일부(버튼 등 실행 경로) 없음: 배포됨/API/슬러그로 표시
## 새로 만들기
- 거의 동일. "템플릿에서" 선택 시 버튼이 "템플릿 고르기"로 바뀜
## 템플릿
- 카테고리 칩 8개(prompts), Figma 6개와 이름 다름(D21)
- 카드에 난이도 배지 추가, 썸네일 왼쪽 위에 아이콘 이모지
- "사용하기"도 상세 시트를 열고 시작 버튼에 포커스(빠진 연결 확인 후 시작)
- 상세 시트(Figma 없음): 읽기 전용 React Flow, 연결 체크리스트, 이름 입력
## 에이전트 빌더
- Figma 05: "자동 저장됨" 대신 명시적 저장 버튼(prompts) + 저장 상태 문구, 기본 정보 카드(이름·설명·아이콘) 추가
- 모델 카드에 온도 슬라이더(Figma는 "파라미터 · 온도 0.7" 텍스트만)
- 기억 카드: 메모리 사용 스위치 + 단기/장기/에피소딕 체크(D7), 임계치 선택 대신 워크스페이스 설정 값 표시
- 스킬 행에 "실행 전 승인" 스위치를 모든 스킬에(Figma는 배지만), 빼기 버튼
- 워크플로 행에 별칭 입력(prompts)
- 테스트·컨텍스트 탭은 Figma 07과 거의 동일. 컨텍스트 탭(단기/장기/에피소딕)은 역할별 필터로 구현
- 버전 드롭다운은 연결된 기본 워크플로의 버전(D24)
## 워크플로 편집기
- Figma 08 배치(팔레트 | 캔버스 | 노드 설정, 하단 실행 로그) 유지
- 팔레트 8그룹 47블록(Figma 5그룹, D23), 그룹별 개수 표시
- 노드에 입출력 포트 행(이름·필수*) 추가 → Figma보다 노드가 큼
- 헤더에 버전 저장·테스트 실행·저장 상태(자동 저장됨/저장 중/실패+다시 시도) 추가, "마켓에 게시" 버튼 대신 배포하기만
- 오른쪽 패널에 노드 설정 | 컨텍스트 탭(prompts 3-6⑤), Figma 인스펙터의 프리셋 저장·3D 결과 미리보기 자리는 미구현(3D 결과는 실행 상세에서)
- 미니맵·줌·실행 취소·자동 정렬 버튼을 캔버스 왼쪽 아래 컨트롤로
## 실행 로그·상세
- Figma 10 표+오른쪽 요약 카드 유지. 표에 소요·토큰·비용 열 추가(prompts), 상태 칩에 "취소됨" 추가
- 필터: 종류·경로(트리거)·에이전트·기간(Figma "오늘 ▾"는 기간 선택으로)
- 실행 ID는 run_ + id 끝 6자리(Figma run_[001])
- 상세 페이지(Figma 없음): 요약 바, 승인 카드, 선택 가능한 간트, 입력·출력 JSON 뷰어, 오류 코드 설명, 3D 뷰어(공개 샘플 Duck.glb)
## 배포 · API
- Figma 09 한 화면 구성을 목록(/deploy) + 엔드포인트 상세 탭으로 나눔(D8). 상세 "개요" 탭이 Figma 배치(엔드포인트 카드·API 키·다른 실행 경로)
- 대상 선택 드롭다운 대신 목록에서 고름, "배포 업데이트(v3)"는 상세의 "배포 업데이트" 버튼
- URL은 /a/{워크스페이스}/{slug}(D10), 키 접두어 moa_live_(D9), 호출 방식 동기/비동기(D11)
- 호출 예제에 JavaScript 탭 추가(Figma는 cURL·Python·OpenAPI), "Swagger에서 열기"는 없음(OpenAPI 탭에서 JSON 보기·다운로드)
- Slack 봇 연결은 "준비 중"으로 비활성
## 마켓
- 13 마켓: Figma 배치도 기준(검색 + 버튼 4개 → 종류·가격·정렬 드롭다운 3개로 추정 구현), 카테고리 칩 7개, 카드 4열. "보유 중" 배지 추가
- 14 상품 상세: Figma와 거의 동일. "제작자 팔로우"·"무료로 3회 실행해 보기"는 1차 범위 밖이라 비활성. README 마크다운 렌더, 리뷰 분포, 버전 기록 탭
- 결제는 모의 결제 다이얼로그 → 완료 화면(복제면 스튜디오에서 열기, 구독이면 호출 주소)
- 15 판매 등록: 5단계 마법사(Figma 배치도 기준), 오른쪽 게시 요약 + 보안 점검 배지
- 16 내 판매: Figma와 같은 구성. 정산 계좌 설정·리뷰 답글은 안내 토스트만
- 구매 내역(/market/purchases): Figma 없음, 라이선스 표 + 리뷰 쓰기
