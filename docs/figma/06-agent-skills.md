## 구성
- 제목 "스킬 추가" / "에이전트가 상황에 맞게 골라 쓸 도구입니다. 워크플로도 스킬처럼 붙일 수 있어요." / 닫기 X
- 탭: 전체 · 기본 · 지식 (RAG) · MCP 도구 · 내 워크플로 · 마켓
- 검색 입력 "스킬 검색"
- 3열 스킬 카드: 아이콘, 이름, 종류 배지(기본 / 지식 / 도구 / MCP · Slack 등), 설명, 오른쪽 아래 `+ 추가` 또는 "추가됨 ✓"(선택 카드는 파란 배경·테두리)
