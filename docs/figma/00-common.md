# 공통 레이아웃 · 컴포넌트 (Figma `컴포넌트` 2:40 — 스크린샷 미추출, 메타데이터 기준)

## 앱 셸 (01·02·03·04·09~17 공통, 1440×900)
- **좌측 사이드바 232px**: 로고 `MOA` + 부제 "AI 에이전트 오케스트레이션", 파란 `+ 새로 만들기` 버튼(전체 폭)
  - 그룹 **만들기**: 홈, 스튜디오
  - 그룹 **운영**: 배포·API, 실행 로그, 연동
  - 그룹 **탐색**: 템플릿, 마켓, 내 판매
  - 하단: 설정, 사용자 카드(아바타, "[사용자 이름]", "MOA 팀 · 소유자")
  - 활성 항목: 연한 파란 배경 + 파란 글자
- **상단 바 60px**: 워크스페이스 스위처 버튼 "MOA 팀 워크스페이스 ▾", 명령 검색 입력 "/ 명령으로 실행하거나 검색 (예: /뉴스요약발송)", 오른쪽 주황 버튼 "승인 대기 2건", 아바타
- **페이지 헤더**: 제목 28px 굵게 + 회색 설명 한 줄, 오른쪽에 주요 버튼(보조 + 주 버튼)
- 콘텐츠 배경은 옅은 회색(surface), 카드는 흰 배경 + 1px 테두리 + radius 8

## 편집기 셸 (05~08)
- 좌측 **축소 사이드바 72px**: `MOA`, 파란 정사각 `+`, 아이콘+라벨 세로 메뉴(홈, 스튜디오, 배포, 로그, 연동, 템플릿, 마켓, 판매), 하단 설정
- 상단 바: `← 스튜디오`, 아이콘 자리, 종류 배지(에이전트/워크플로) + 이름, 부제 "자동 저장됨 · v3 초안", 가운데 탭, 오른쪽 "버전 v3 ▾", "마켓에 게시", 파란 "배포하기"
