2. **무엇을 만들까요?** 카드
   - 오른쪽 세그먼트 토글: 에이전트 | 워크플로
   - 큰 텍스트 영역(예시 문장: "제품 디자인팀을 돕는 에이전트를 만들어줘…")
   - 버튼: `설명으로 초안 만들기`(주) · `템플릿에서 시작` · `빈 상태로 직접 만들기`(Ghost)
   - 오른쪽 안내: "에이전트는 모델·스킬·워크플로를, 워크플로는 노드를 자동 구성합니다"
3. **지표 카드 4개**: 오늘 실행 [000]회(에이전트·워크플로 합산) / 실행 성공률 [00]%(재시도·Fallback 적용 후) / 이번 달 토큰 비용 ₩[000,000](예산 한도 대비 [00]%) / 배포 중 [0]개(API 엔드포인트 기준)
4. **최근 작업**(좌, 넓음) — "스튜디오에서 전체 보기 →"
   - 행: 아이콘, 종류 배지(에이전트 파랑/워크플로 회색), 이름, 보조 줄(모델·스킬 수·워크플로 수 / 트리거·노드 수), 오른쪽 상태 배지(초안 v3, 배포됨, 마켓 판매 중)
5. **추천 템플릿**(우) — "더 보기 →", 3개 행(아이콘, 이름, "에이전트 · 스킬 3개"/"워크플로 · 노드 6개")
6. **승인이 필요한 작업**(우 하단, 화면 밖) — "AI 뉴스 요약 발송 · 메일 발송 전 승인 대기 · 확인 →"

## 이동
- 최근 작업 행 → 에이전트 빌더/워크플로 편집기, 템플릿 행 → 템플릿 상세, 승인 "확인 →" → 실행 상세
- `템플릿에서 시작` → /templates, `빈 상태로 직접 만들기` → /studio/new
