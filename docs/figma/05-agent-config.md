## 구성 (편집기 셸 + 3열)
- 상단 탭: **구성** · 테스트·컨텍스트 · 배포 · 로그 / 오른쪽 "버전 v3 ▾", `마켓에 게시`, `배포하기`
- 1열
  - **모델** 카드: 오른쪽 "파라미터 · 온도 0.7", 기본 모델 선택, 실패 시 대체 모델 선택
  - **역할 지시문** 카드: 배지 "고정됨 · 압축 제외", 텍스트 영역
  - **기억 · 컨텍스트** 카드: 체크박스 단기(세션) / 장기(사용자 프로필) / 에피소딕(과거 실행), 토큰 예산 임계치 "컨텍스트 창의 70%", 초과 시 "오래된 비고정 블록 자동 요약"
- 2열
  - **스킬 4** 카드 + `+ 스킬 추가`: 스킬 행(아이콘, 이름, 종류 배지 기본/지식/MCP/도구, 설명, 오른쪽 켜기 스위치, MCP 도구는 "실행 전 승인" 주황 배지)
  - **워크플로 2** 카드 + `+ 워크플로 연결`: 행(이름, "입력: … → 출력: …", `열기 ↗`), 하단 설명
- 3열 **디버그 & 미리보기**: `컨텍스트 보기 · 72%`, `새 세션`, 채팅(사용자 말풍선 오른쪽 파랑, 응답 카드 안에 도구 호출 줄: 스킬/워크플로 배지 + 상태 완료/실행 중 · Job #ID, 3D 결과 미리보기 자리, 승인 대기 카드 `승인하고 보내기` `수정`), 하단 입력 "메시지 입력 · '기억해줘'로 장기 기억 저장 · /로 스킬 직접 호출" + `보내기`
