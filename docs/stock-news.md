# 국내 주식 카드뉴스

브랜치: `feat/stock-news-card-generation` (이슈 번호 없음).

## 구현 범위

`/stock-news` 화면은 백엔드에 저장된 최신 뉴스 JSON을 읽어 표지 1장 + 국내 뉴스 4장을
1080×1350 JPEG로 자동 생성한다. 기사 입력·JSON 업로드 없이 표시한다.
이미지를 눌러 크게 보거나 각 JPEG와 원문 출처 JSON을 내려받을 수 있다.
생성 날짜, 예약 수집 상태, 실패 시 오류와 이전 성공본을 표시한다.

템플릿의 **국내 주식 카드뉴스(tpl-25)** 또는 도구 노드 **국내 주식 카드뉴스**에서도
이 화면으로 이동할 수 있다. 인스타그램 게시와 실제 게시 승인은 다음 단계다.

현재 서버·LLM 키가 없어 운영 자동 수집은 아직 활성화되지 않았다.
목 API 모드에서는 뉴스 대신 실제 백엔드 연결 안내를 표시하며 실제 수집을 가장하지 않는다.

## 실제 연결

1. 백엔드의 같은 이름 기능 브랜치 코드를 적용하고 `docs/stock-news.md`의 DB·키·예약 설정을 준비한다.
2. 웹은 `pnpm dev:backend`로 실행한다. 다른 서버면 `MOA_BACKEND_URL`을 지정한다.
3. 실제 서버의 계정으로 로그인한 뒤 `/stock-news`에서 초기 수집을 요청한다.
4. 이후에는 서버가 매일 오전 7시(KST)에 수집하며, 웹을 열면 DB의 최신 성공본이 표시된다.

PC를 꺼도 실행하려면 기존 localhost 대신 상시 서버에 백엔드와 영속 DB를 배포해야 한다.
서버 설정·키는 채팅이나 Git에 넣지 않고 서버의 비밀 환경변수/자격증명 볼트에서 관리한다.

## 백엔드 작업 위치

기존 실행 중인 `moa-backend`를 변경하지 않기 위해 Git worktree를 사용했다.
위치는 `moa-web/tmp/moa-backend-stock-news`, 실제 Git 저장소는 `moa-backend`다.
이 폴더에서 백엔드 브랜치의 커밋과 push를 수행할 수 있다. 프론트 PR에 이 폴더를 추가하지 않는다.

## 검증과 디자인

- 프론트 단위 테스트: 덱 구성·출처 보존·중복·주소 형식.
- 실제 백엔드 API 계약에 테스트용 RSS/LLM 대역을 넣고 로그인 → 최신 카드 자동 표시 →
  JPEG 1080×1350 다운로드를 Playwright로 확인했다. 실제 LLM 호출 검증과는 구분한다.
- Figma 저장본에 카드뉴스 화면이 없어 기존 MOA 토큰·사이드바·카드 UI를 사용해 설계했다.
  새 화면은 5장 미리보기와 출처·수집 상태 영역을 추가했다. 기존 편집기 레이아웃은 그대로 사용한다.
- 새 생성 기능은 코드 기반 Canvas 렌더링이며 외부 이미지 생성 API를 요구하지 않는다.

## PR 제안

프론트·백엔드 각각 독립 PR이 필요하다. 백엔드 변경이 400줄을 넘으므로
수집·저장 핵심과 예약·API/노드 연결을 나눠 검토하는 방식을 권한다.
실제 배포·클라우드 생성·유료 모델 호출·인스타 게시·push·PR 생성은 수행하지 않았다.
